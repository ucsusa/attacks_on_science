## Readme for attacks on science (AOS) data flow

The scripts in this repository pull rss daily, bring the descriptions and titles through a search term filter, read in the full text articles, and bring them through another search term filter, develop a workbook for human coding, and then process the coded data for a data dashboard.

An ‘attack on science’ is an action, statement, or decision that results in the censoring, manipulation, forging, or misinforming on scientific data – raw or processed, analysis processes/methodologies, or results and conclusions conducted within the federal government or with federal funds.
